# Tradução PT-BR — WWE SmackDown vs. Raw 2011 (PS2)

![WWE SmackDown vs. Raw 2011 - Capa](capa.jpg)

Patch de tradução para Português Brasileiro do jogo **WWE SmackDown vs. Raw 2011** (PlayStation 2), feito por fã para fãs.

## O que vem no download

* `WWE SmackDown vs Raw 2011 (PT-BR).xdelta` — o patch de tradução (formato xdelta)
* `LEIAME.txt` — instruções completas de instalação (em português)

## Requisitos

* ISO original e limpa do jogo **WWE SmackDown vs. Raw 2011** Americana (SLUS_219.39) de PS2. Sem outras modificações
* [Delta Patcher](https://github.com/marco-calautti/DeltaPatcher) — ferramenta gratuita para aplicar o patch

## Como instalar

1. Baixe o [Delta Patcher](https://github.com/marco-calautti/DeltaPatcher/releases) para o seu sistema operacional
2. Baixe o arquivo `WWE SmackDown vs Raw 2011 (PT-BR).xdelta` deste repositório (aba **Releases** — vem dentro do arquivo .zip)
3. Abra o Delta Patcher, selecione o modo Apply Patch
4. Selecione o `WWE SmackDown vs Raw 2011 (PT-BR).xdelta`, sua ISO original e o nome do arquivo de destino
5. Clique em Apply e aguarde a conclusão

Instruções detalhadas passo a passo estão no arquivo `LEIAME.txt`.

## Aviso legal

Este repositório não distribui nenhum arquivo do jogo original. O patch apenas modifica bytes de uma ISO que o usuário já possui legalmente. Nenhum conteúdo protegido por direitos autorais da THQ/Yuke's/WWE está incluído aqui.
